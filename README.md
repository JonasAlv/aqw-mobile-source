# AQW Pocket mod

This project is a customized mod of **AQW-Pocket** client for Android and Desktop.

## Features
- **Automation Engine:** Creates a new automation menu overlay.
- **AQWApi Integration:** Use our `aqw-api` backend, enabling scripting, smart combat, map-wide monster hunting, and auto-questing.
- **Standalone:** unhooks the original client's auto-updater to ensure tools are never accidentally overwritten by upstream updates.
