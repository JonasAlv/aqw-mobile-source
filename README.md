# AQW Pocket - Automation Fork

This project is a customized fork of Anthony's **AQW-Pocket** client for Android and Desktop.

## Features
- **Automation Engine:** Replaces the default interface with a brand new, highly robust automation menu overlay.
- **AQWApi Integration:** Powered by our custom `aqw-api` backend, enabling powerful scripting, smart combat, map-wide monster hunting, and auto-questing directly from your mobile device.
- **Standalone:** Safely unhooks the original client's auto-updater to ensure your modded automation tools are never accidentally overwritten by upstream updates.

## Building
Run `./build_android.sh` to compile the modded Android APKs.
